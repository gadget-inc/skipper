# Contributing

The contributing guide lives on the docs site at [gadget-inc.github.io/skipper/contributing](https://gadget-inc.github.io/skipper/contributing/getting-started/):

- [Getting Started](https://gadget-inc.github.io/skipper/contributing/getting-started/) — prerequisites, setup, and project layout
- [Building and Deploying](https://gadget-inc.github.io/skipper/contributing/building-and-deploying/) — deploy commands, fixture smoke tests, cleanup
- [Testing and Linting](https://gadget-inc.github.io/skipper/contributing/testing/) — test commands, linting, code generation
- [Web UI](https://gadget-inc.github.io/skipper/contributing/web-ui/) — dev mode, available routes, live-reload
- [Watching Logs](https://gadget-inc.github.io/skipper/contributing/watching-logs/) — stream and filter logs during development
- [Profiling and PGO](https://gadget-inc.github.io/skipper/contributing/profiling/) — collect profiles, generate PGO data
- [Contribution Workflow](https://gadget-inc.github.io/skipper/contributing/workflow/) — PRs, CI, Docker image builds
