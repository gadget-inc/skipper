# web/CLAUDE.md

## Commands

```bash
direnv exec . pnpm --filter web start   # Run dev server (localhost:3000)
direnv exec . pnpm install              # Install deps (run from repo root, not web/)
direnv exec . buf generate              # Regenerate protobuf types into src/gen/
```

## Architecture

Server-side rendered dashboard using HTMX — not a SPA, no client-side framework. TypeScript runs directly via `node --experimental-transform-types` with no build step or bundler.

- **Routing**: `@remix-run/fetch-router` maps URLs to handler functions that return `Response` objects
- **Data**: All state comes from `controller.getClusterState({})` via gRPC (Connect protocol). The client is exported from `src/client.ts`
- **Views**: Functions that return HTML strings. Pages use `layout(title, content)` for the full document shell. Partials return raw HTML fragments for HTMX swap targets
- **Styling**: All CSS is inline in `src/views/layout.ts` using CSS variables. No external stylesheets
- **HTMX**: Partials under `src/views/partials/` serve HTML fragments polled by `hx-get`/`hx-trigger` attributes

## Key Conventions

- All imports use `.ts` extensions (Node.js ESM with `module: "nodenext"`)
- `src/gen/` is generated by `buf generate` — never hand-edit these files
- Dependencies are managed via pnpm workspace from the repo root
- Environment variables: `CONTROLLER_HOST` (default: localhost), `CONTROLLER_PORT` (default: 50051), `PORT` (default: 3000)
